2. Сбор информации

Просмотр сайта

Документы и цены открываются в обычном браузере без регистрации. Для доставки страницы хостинг GitHub Pages получает технические сведения запроса, включая IP-адрес и данные браузера. Настройки, сохранённые расчёты и история текстов могут храниться в памяти браузера на вашем устройстве.

Аккаунт, доступ и заказы

При запуске Mini App Telegram передаёт подписанные данные входа, включая числовой ID, имя и, при наличии, имя пользователя. ID связывает аккаунт со сроком доступа, остатком генераций и заказами. Для учёта покупки обрабатываются номер заказа, тариф, сумма, способ и статус оплаты. После подключения онлайн-оплаты платёжный сервис получает сведения о заказе и возвращает подтверждение. Банковские реквизиты вводятся на стороне платёжного сервиса.

Тексты и обращения

Когда вы нажимаете «Сгенерировать», сервер передаёт введённый текст, выбранные параметры и инструкции через VseGPT модели, которая готовит ответ. Уберите из примеров имена клиентов, телефоны и номера заказов. Обращение в поддержку сохраняется вместе с Telegram ID, датой и описанием ошибки. Чтобы ответить, автор может получить эти сведения в Telegram. Скриншоты в личный чат вы отправляете по своему выбору.

Данные аккаунта и запросов обрабатываются для предоставления выбранной услуги и исполнения соглашения. Данные о расчётах с пользователями также обрабатываются для выполнения обязанностей по закону. Если для отдельной операции требуется согласие, оно запрашивается отдельно.

Сведения также могут предоставляться по законному запросу уполномоченного органа.

Объём передачи ограничивается целью операции. Если для передачи требуется отдельное согласие, оператор запрашивает его до передачи. Трансграничная передача, если она осуществляется, проводится с соблюдением требований законодательства РФ.

Локальную историю можно удалить очисткой данных сайта в браузере.
